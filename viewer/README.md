# Bonsai BIM Viewer

Web-based IFC model viewer with agent chat. Renders building models generated by Bonsai AI and connects to the bim_operator agent for interactive Q&A.

## Quick Start

```bash
cd /Users/alanknudson/Applications/Bonsai_ai
./scripts/serve-bonsai-viewer.sh
```

Or manually:

```bash
# Terminal 1: chat proxy (connects to OpenClaw agents)
node viewer/src/chat-proxy.js

# Terminal 2: Vite dev server
cd viewer && npm run dev
```

Open http://127.0.0.1:5173

## Loading Models

Default: loads `out/retail_terrace_concept/retail_terrace_concept.ifc`

Load a specific model via URL param:
```
http://127.0.0.1:5173/?model=/out/techridge_initial_shell/techridge_initial_shell.ifc
```

List available models: `curl http://127.0.0.1:5174/models`

## Architecture

```
Browser (5173)                    Chat Proxy (5174)
┌─────────────────┐               ┌──────────────────┐
│ Three.js + web-ifc │             │ POST /ask        │
│ IFC 3D viewport   │ ──fetch──► │   → bim_operator │
│ Inspector panel    │             │ POST /research   │
│ Chat panel         │             │   → bim_maintainer│
│ Search + toolbar   │             │ GET /models      │
└─────────────────┘               └──────────────────┘
```

- **viewer.js** — web-ifc WASM parser + Three.js rendering (single-threaded mode)
- **inspector.js** — IFC property viewer with Properties/Geometry/Relations tabs
- **chat.js** — agent chat with BIM context awareness
- **chat-proxy.js** — Node.js HTTP proxy spawning OpenClaw agents
- **app.js** — EventBus controller (same pattern as openclaw_agents/viewer)
- **styles.css** — glassmorphism design system

## Requirements

- Node.js 18+
- OpenClaw CLI (`openclaw` in PATH)
- IFC files in `out/` directory

## Keyboard Shortcuts

- `/` — focus search
- `Escape` — deselect element
- `f` — fit all to view
- `w` — toggle wireframe
